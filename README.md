## Description

![Banner6](https://i.ibb.co/zh4g1GNq/1000039604-removebg-preview.png)


Oryn is an all-in-one document suite built for your phone. It brings writing, editing, signing, converting, and collaborating into one app, so you no longer need a different website for every small task. Its clean, minimal interface keeps the focus on your work, whether you’re drafting an essay, polishing a report, filling in a form, or putting together a presentation. At its core is the Sugarcane Editor, which supports rich formatting and embedded media, and exports to PDF, DOCX, or SCD. Around it sits a full toolkit: PDF markup, signing, merging, and compression, spreadsheets, charts, mind maps, file conversion, image editing, and developer tools. The app also adds offline use, templates, a built-in scanner, and PIN lock, and an optional on-device AI suggests your next sentence as you type.

What sets Oryn apart is that it is private and free. Everything runs on your device, so your documents are processed locally, and the AI model works offline once downloaded. Live collaboration, chat, calls, and file transfer run peer-to-peer over WebRTC, so your edits and messages go straight to your collaborators and never pass through a central server. There are no accounts, no ads, and no limits, and every tool is free. You can share a finished document as a PDF, DOCX, or SCD file, or send a single link that opens it in one tap. Whether you’re a student, a professional, or just someone who needs to get a document done, Oryn makes the work quick, organized, and simple.

## Collaboration Tools

In Oryn, there are various tools which support collaboration or can connect users together in one united workspace. The tools which use collaboration features are listed below:

- ❖ Collab Editor
- ❖ Text
- ❖ Call

ⓘ All collaboration tools in Oryn are built using **PeerJS** and **WebRTC**, which allow real-time communication directly between users’ devices. This means that your files, edits, and messages never pass through Oryn’s servers, ensuring full privacy and security. By using this peer-to-peer approach, Oryn keeps your data safe while still enabling features like live collaboration, file sharing, and team editing.  

Learn more about PeerJS here: [https://peerjs.com/](https://peerjs.com/)
